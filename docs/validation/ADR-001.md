- PASS: package build verification and licence/provenance inventory.

- MEASURED: 3.18% mean whole-benchmark slowdown on alternating Rosenbrock n=1000,m=10 runs;
  values, iterations and evaluations match. No speedup claim. Raw JSON is under
  benchmarks/results; BENCHMARKS.md describes hardware, configuration and limitations.

The CI workflow is configured for Linux/Windows on stable and Rust 1.80, but remote
CI has not run in this local task. Fortran regeneration was not needed or performed.
This validates the library interface, not any downstream AL implementation.

ADR-002 supersedes the interpretation of this single-case observation as isolated driver overhead.
